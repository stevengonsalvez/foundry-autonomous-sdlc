# Explainer
`foundry-autonomous-sdlc.html` is one self-contained page (no external requests, light and dark) on the SDLC loop, ledger, CD and control center.
Open it in a browser; it works offline. Diagrams are inline SVG with titles and descriptions.
Facts checked 2026-10-11 against `docs/architecture.md`, `docs/cd.md` and `docs/decisions.md`.
When those docs change, update the page in the same commit.
